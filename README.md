The Chrome Web Store page for this extension can be found [here](https://chromewebstore.google.com/detail/nyt-minimax/nolaoefloihgjikalhcaaojebhocbjle).

MiniMax is an add-on for the New York Times' Mini and Midi crosswords.

This extension allows users to increase the font size of the crossword hints, change what side the hints are on, quickly navigate between previous and future puzzles, and easily access the crossword archives.



MiniMax is not affiliated with The New York Times.
