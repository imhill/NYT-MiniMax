The Chrome Web Store page for this extension can be found [here](https://chromewebstore.google.com/detail/nyt-minimax/nolaoefloihgjikalhcaaojebhocbjle).

NYT MiniMax is an add-on for the New York Times' Mini and Midi crosswords.

This extension allows users to increase the font size of the hints on the crossword, change the side of the hints, quickly navigate between previous and future puzzles, and access the crossword archives.
